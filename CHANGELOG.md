# Changelog

## Unreleased

### Added

- Historical session discovery, resumable downloads, validated caches and offline replay.
- Timing, Driver, Conditions, Track and Events views with responsive terminal layouts.
- Playback speeds, deterministic seeking, driver/lap navigation and manual video alignment.
- Source-quality indicators, provisional lap bests, timed control reports and evidence-based context.
- Bundled generated demo, standalone native binaries and Windows/Linux/macOS build automation.
- MIT code license, data interpretation reference and dependency notices in release archives.

### Limitations

- Live timing is unavailable; generated demo data is separate from recordings.
- Linux/macOS builds remain experimental pending native interactive terminal validation.
- The reference validated cache load exceeds the two-second target; visible terminal latency is unverified.
- There is no stable public release yet. Provider archives do not reconstruct original delivery or revision history.
